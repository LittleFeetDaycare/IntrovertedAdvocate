# Simply Me — Personal Lifestyle Blog

A responsive starter website for a personal lifestyle blog.

## Files
- `index.html` — main website
- `styles.css` — responsive styling

## Customize
1. Replace the "YOUR PHOTO" placeholders with your own photos.
2. Change `Simply Me` and the tagline in `index.html`.
3. Replace the sample post text and links with your real posts.
4. Change the email address in the Contact section.
5. Update the social media links.
6. Upload the files to GitHub Pages, Netlify, Vercel, or another static host.

The design is mobile-friendly and requires no backend.


## Custom palette
Purple, black, and sage green.
